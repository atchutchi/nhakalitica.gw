{% translate "1. Respeito e inclusão" %}

{% translate "Trata todas as pessoas com respeito. Não são permitidos assédio, intimidação, discriminação, discurso de ódio, ameaças ou ataques pessoais, incluindo por origem, nacionalidade, género, religião, deficiência, idade, orientação sexual ou posição profissional." %}

{% translate "2. Identidade e informação verdadeira" %}

{% translate "Usa a tua identidade real e apresenta informação profissional correcta. Não falsifiques qualificações, experiência, relações com organizações, oportunidades ou referências." %}

{% translate "3. Privacidade e confidencialidade" %}

{% translate "Respeita as escolhas de visibilidade dos membros. Não copies, publiques, vendas ou distribuas perfis, CV, contactos, mensagens ou outros dados sem autorização. Não uses ferramentas para recolher dados em massa." %}

{% translate "4. Contacto profissional" %}

{% translate "Contacta outros membros com uma finalidade profissional clara e relevante. Não envies spam, insistência abusiva, publicidade enganosa ou propostas que ocultem a entidade, a finalidade ou condições essenciais." %}

{% translate "5. Organizações e oportunidades" %}

{% translate "Se representares uma organização, deves ser um membro aprovado e estar autorizado a agir em seu nome. As oportunidades devem ser legítimas, suficientemente claras e respeitar as regras laborais e profissionais aplicáveis." %}

{% translate "6. Segurança da comunidade" %}

{% translate "Não tentes contornar permissões, aceder a contas alheias, introduzir código malicioso, explorar vulnerabilidades ou usar a plataforma para fraude, corrupção, violência ou qualquer actividade ilícita." %}

{% translate "7. Denúncia e cooperação" %}

{% translate "Comunica comportamentos ou conteúdos preocupantes pelos mecanismos disponíveis ou pelo contacto indicado abaixo. Fornece informação verdadeira e coopera de boa-fé. Não uses denúncias para retaliar, perseguir ou prejudicar outra pessoa." %}

{% translate "8. Moderação e consequências" %}

{% translate "A equipa Kalitica pode analisar denúncias, pedir esclarecimentos, remover conteúdos, limitar funcionalidades, suspender ou encerrar contas. A resposta considera a gravidade, o contexto, a repetição, o risco para terceiros e as obrigações aplicáveis." %}
