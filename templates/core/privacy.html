{% translate "1. Responsável e contacto" %}

{% translate "A Kalitica Networking Society é responsável pelo tratamento dos dados pessoais usados para operar esta plataforma. Questões e pedidos relacionados com privacidade podem ser enviados para o contacto indicado no final desta política." %}

{% translate "2. Dados que recolhemos" %}

{% translate "Tratamos os dados fornecidos na conta, candidatura e perfil profissional, incluindo identidade, contacto, residência, ligação à Guiné-Bissau, percurso, competências, fotografia e CV quando submetidos. Tratamos também registos de decisões, preferências de visibilidade, interacções dentro da plataforma e dados técnicos necessários à segurança e ao funcionamento." %}

{% translate "3. Finalidades" %}

{% translate "Usamos os dados para criar e proteger a conta, confirmar o email, analisar a candidatura, gerir a adesão, apresentar o perfil conforme as escolhas do membro, permitir pesquisa e contacto entre membros aprovados, moderar a comunidade, responder a pedidos e cumprir obrigações aplicáveis." %}

{% translate "4. Fundamentos do tratamento" %}

{% translate "Tratamos dados para prestar o serviço solicitado e gerir a relação com o membro, com base no consentimento quando a escolha é opcional, para proteger a plataforma e a comunidade e para cumprir obrigações legais aplicáveis. Podes retirar consentimentos opcionais sem afectar o tratamento anterior à retirada." %}

{% translate "5. Acesso e visibilidade" %}

{% translate "A candidatura e os dados administrativos são acessíveis apenas à equipa autorizada. Os membros só acedem à pesquisa e aos restantes perfis depois de aprovados. O teu perfil profissional só fica visível quando estiver aprovado e escolheres publicá-lo. Os dados de uma organização representada só são apresentados quando autorizares essa visibilidade." %}

{% translate "6. CV e contactos" %}

{% translate "O CV e os dados de contacto exigem cuidado adicional. A plataforma deve apresentá-los apenas nos contextos e níveis de acesso definidos pelo membro e permitidos pelo serviço. Não deves incluir no CV informação pessoal que não seja necessária para fins profissionais." %}

{% translate "7. Prestadores e transferências" %}

{% translate "Podemos recorrer a prestadores de alojamento, base de dados, armazenamento, email, segurança e suporte técnico. Limitamos o acesso ao necessário e exigimos medidas adequadas de confidencialidade e protecção. Quando um tratamento envolver outro país, adoptamos as salvaguardas aplicáveis ao contexto do serviço e dos titulares." %}

{% translate "8. Conservação e eliminação" %}

{% translate "Conservamos os dados enquanto a conta estiver activa e durante os períodos necessários às finalidades descritas. Quando pedires a eliminação, a conta fica desactivada durante 30 dias para permitir recuperação. Depois desse prazo, eliminamos ou anonimizamos os dados pessoais, mantendo apenas os registos administrativos legalmente necessários. As cópias de segurança são eliminadas segundo o respectivo ciclo técnico de retenção." %}

{% translate "9. Segurança" %}

{% translate "Aplicamos controlos técnicos e organizativos destinados a limitar acessos indevidos, perda, alteração ou divulgação. Nenhum sistema elimina todo o risco. Deves usar uma palavra-passe exclusiva e comunicar rapidamente qualquer suspeita sobre a conta." %}

{% translate "10. Os teus direitos" %}

{% translate "Podes pedir informação e acesso aos teus dados, correcção, eliminação, limitação ou oposição quando aplicável e uma cópia dos dados que forneceste num formato adequado. Também podes retirar consentimentos opcionais e apresentar uma reclamação à autoridade competente. Avaliaremos cada pedido segundo a legislação aplicável e os direitos de terceiros." %}

{% translate "11. Actualizações" %}

{% translate "Podemos actualizar esta política quando o serviço ou os requisitos aplicáveis mudarem. A versão e a data em vigor são apresentadas no início da página. Alterações relevantes serão comunicadas pelos meios disponíveis." %}
